Suara Dua Arah: sherpa-onnx / Apple Native

Gunakan arsitektur sherpa-onnx INT8 di Android flagship (Snapdragon NPU) atau Apple Native Offline Model di iOS. Latensi stabil di 420–480ms tanpa round-trip network.

2

Kanji Visual: CameraX + CoreML / ML Kit

Paling instan untuk membaca menu & plang jalan. Apple Live Text dan Google ML Kit Text Recognition v2 mengeksekusi OCR huruf Kanji langsung di memori kamera dalam 180–210ms.

3

Hands-Free Traveling: Timekettle Earbuds

Untuk percakapan tatap muka tanpa perlu menyodorkan handphone bergantian, Timekettle WT2 Edge memberikan pengalaman paling natural dengan latensi ~650ms via dual earbuds.
